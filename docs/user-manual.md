# openpet 用户手册

> 面向普通用户的使用说明。遇到问题先看文末 FAQ；反馈入口见「关于」页。

## 1. 安装与更新

- 系统要求：Windows 10 / 11（64 位）。
- 从 [GitHub Releases](https://github.com/Furina-he/openpet/releases) 下载：
  - **`OpenPet-Setup-X.Y.Z.exe`（推荐）**——向导式安装，**可自定义安装路径**；默认装到当前用户目录（不需要管理员权限），并创建桌面快捷方式。
  - **`OpenPet-X.Y.Z-portable.exe`**——免安装单文件版，双击即用；**不支持自动更新**，升级请手动下载新版覆盖。
- **SmartScreen 提示「未知发布者」**：本项目暂未购买代码签名证书，首次运行请点 `更多信息 → 仍要运行`（正式版会逐步加入签名）。
- **自动更新**（安装版）：应用会在启动与每日后台检查新版本（Hub → 系统 → 通用 → 「自动检查更新」可关闭），发现新版只提醒**不自动安装**；到 Hub → 系统 → 关于 点「下载」，完成后点「重启更新」即可升级，你的对话与数据不受影响。也可以随时在关于页手动「检查更新」。
- **卸载**：控制面板卸载**不会删除**你的数据（对话/记忆/角色都在 `%APPDATA%\openpet`）；重装后数据自动恢复。想彻底清空就手动删除该目录。
- 也可从源码运行：安装 [Node.js ≥20](https://nodejs.org) 与 pnpm 9，然后在仓库根目录执行 `pnpm install && pnpm dev`。

## 2. 首次启动引导

第一次启动会出现 4 步引导，约 90 秒：

1. **选语言**——左下角下拉框可切换 简体中文 / English，界面即时切换。
2. **配置模型（连接一个大脑）**——选择一个模型提供商（OpenAI / Claude / Gemini / 通义 / DeepSeek / 自定义中转…），粘贴 API Key，点「拉取模型列表」后挑一个模型；没有 Key 也可以选本地 Ollama，或先「暂时跳过」。
3. **选角色**——默认伙伴即可开始，之后可在角色库导入更多角色。
4. **说第一句话**——点一句预设话术，角色就会回应你。

引导可随时点「跳过」，之后在 Hub 设置里都能补配。

## 3. 日常使用

- **托盘**：右下角托盘图标——左键 显示/隐藏角色，双击 打开聊天，中键 切换鼠标穿透，右键 完整菜单（不打扰 / 打开 Hub / 退出）。
- **热键**（可在 Hub → 系统 → 热键 修改）：呼出聊天、显示/隐藏角色、鼠标穿透、不打扰、打开 Hub。
- **鼠标穿透**：开启后点击会穿过角色落到桌面，角色不再挡操作；再次触发热键或托盘中键恢复互动。
- **聊天气泡**：角色上方的浮层气泡显示回复；长文自动折叠，点「展开」看全文。
- **语音**：聊天输入框的麦克风按钮=点击开始录音、再点结束并转写；在 系统 → 通用 里开启「自动朗读回复」可让角色读出回复（需先配置 TTS 模型）。
- **右键角色**：快捷菜单（聊天 / 穿透 / 显隐 / 大小 / 设置）。

### 调整角色大小与位置

- **三个入口**：光标停在角色身上按住 Ctrl 滚动滚轮（触控板双指捏合同样有效），每格 5%，脚下会显示当前百分比；右键角色 → 大小；托盘右键 → 角色大小（开着鼠标穿透、点不到角色时用它）。Hub → 系统 → 显示 里也有滑块和「恢复 100%」。
- **每个角色记住自己的大小**：切换角色或换形象后，各自回到上次的大小。缩放以脚底为锚，放大时如果会超出屏幕，角色会自动挪回屏内；小屏幕上可选的最大值会相应变小。
- **像素风形象**：只在清晰的整数倍之间切换，边缘始终锐利。
- **位置记忆**：角色会记住在哪块显示器、哪个位置；重启后回到原处。拔掉副屏后角色先回到主屏，10 秒内插回会自动回到副屏原位；分辨率或缩放比例变化时按相对位置重新摆放。

## 4. 角色包

> 一个角色 = **灵魂**（人设/世界设定/开场白）+ **肉体**（模型与动作表情）+ **声音**（音色）。三者可以分开分发，也可以分开更换。

- 在 Hub → 角色 → 角色库 点「导入 .dspack」或「导入文件夹」，确认摘要后即可加入；**双击卡片**热切换当前角色。
- **市场**（角色库 → 市场）：从社区索引安装完整角色包、灵魂包（`.dssoul`，装的时候选一个已装角色借形象）或形象包（`.dsbody`）；下载物一律做 sha256 校验，安装前会展示原文许可条款。
- **换形象**（角色库 → 形象）：给已有角色换上形象包，**记忆、对话历史、人设与音色全部保留**——还是同一个角色，只是换了身体；情绪/动作表会随新形象变化。内置角色只读，先「复制后编辑」再换。
- 支持三类形象：**VRM**（3D）、**Live2D**（Cubism 4/5）与**帧动画**（2D 逐帧图集，像素风、手绘风都行），换形象可以在三类之间互换。
- **帧动画形象**：情绪和动作会切到图集里对应的那一行（比如开心先跳一下、难过一直垂头），没有专门画出来的动作（点头、歪头……）由程序化的 2D 动作补上；拖着它左右走会播跑动的那两行。像素风形象请在 角色 → 编辑器 → 动画 & 情绪 里把「缩放方式」设为「像素」，放大后边缘才锐利、呼吸时不会糊；绘画风保持「平滑」。
- **把 Codex 宠物带进 openpet**：用 Codex 孵出来的宠物（`~/.codex/pets/<名字>/`）可以用仓库里的离线脚本转成形象包：`node scripts/codex-pet-to-body.mjs ~/.codex/pets/<名字>`（像素风加 `--pixel`），产物 `.dsbody` 在 角色库 → 形象 → 导入，再「应用到角色」即可。只转换自己孵化或已获授权的宠物——Codex 内置宠物属于 OpenAI，不要再分发。
- **Live2D 角色需要自行下载 Cubism Core**（`live2dcubismcore.min.js`，Live2D 官网免费提供）：Hub → 系统 → 数据 → 「打开数据目录」，在其中新建 `cubism` 文件夹放入该文件后重启；缺失时角色会降级为占位表情，不影响其它功能。

## 5. 长期记忆

> 角色会把聊天里值得长期记住的事整理进一本 markdown 记事本：**用户档案、人物、话题**所有角色共用，**我们的关系、共同经历**每个角色各一份。总开关在 Hub → 系统 → 隐私 → 长期记忆。

- **在哪看**：Hub → 对话 → 记忆。默认是**关系图谱**：中间的「我」是你的档案，暖色点是人物、蓝色点是话题、紫色点是你和角色的关系与经历；点与点之间的线，就是页面里互相提到的地方。
- **怎么操作**：滚轮缩放、拖空白处平移、拖动节点重新摆放；鼠标悬停会高亮它和相邻的点，单击在右侧打开阅读栏（正文里的链接可以直接点过去，底部「反向链接」列出哪些页面提到了它），双击放大居中。图的摆放会被记住，下次打开不会重新乱排。
- **三个开关**：「未建页面」显示被提到、但还没有页面的名字（空心点，点开可一键建成人物页或话题页）；「提及」显示正文里提到了、但没加链接的关系（虚线）；「孤立页面」是没有任何连线的页，统一收在右下角。
- **被想起的光环**：最近聊天时真正被角色想起过的人物 / 话题会带一圈柔光（1 小时内最亮，7 天后消失）；阅读栏里能看到它被想起过几次、上次是什么时候。
- **试一句**：点工具条的「💭 试一句」，输入一句你可能会说的话，看看角色会想起哪些页面（关键词命中还是语义相近）、一共会带上多少字，还能展开看带给模型的原文——和真实聊天走的是同一套检索。
- **编辑**：切到「列表」，或在阅读栏点「编辑」，可以直接改 markdown。`[[名字]]` 是指向另一页的链接；某一节不想被自动整理改写，点节名旁的 🔓 把它锁定。人物 / 话题可以在阅读栏「重命名」，所有提到它的链接会一起改好。
- **用 Obsidian 打开**：记忆文件夹本身就是一个 Obsidian 仓库。点「打开文件夹」找到它，在 Obsidian 里选「打开本地仓库」即可看到同一张图（分色已预设好）；在 Obsidian 里改的内容、加的属性，openpet 都会照常读取，下次自动整理也不会丢。
- **旧记忆自动升级**：第一次打开这个版本时，旧记忆会自动转成新格式（人物 / 话题的文件名改成中文标题，页面之间互相提到的地方补上链接）；转换前整个记忆文件夹会先备份到数据目录下的 `memory.bak-v1-<时间戳>`。
- **换了嵌入模型**：默认嵌入模型换掉后，记忆的向量会在下次聊天时自动重算，不用手动处理。

## 6. 数据与隐私

- 所有数据（对话、记忆、角色、知识库、配置）保存在本地 `%APPDATA%/openpet`（Hub → 系统 → 数据 → 「打开数据目录」可直达）。
- **备份**：数据页可导出 `.dsbak` 备份（含对话历史、人设演进、长期记忆；不含 API Key）；导入 `.dsbak` 会在下次启动时整体替换当前数据，旧数据自动备份为 `.bak`。
- **API Key 以明文随配置保存在本地**，不会上传到任何服务器；请勿把数据目录或备份分享给他人。
- 长期记忆、知识库 RAG、剪贴板/截屏等系统访问均有独立开关（Hub → 系统 → 隐私），默认最小化。

## 7. FAQ

**Q1：我的 API Key 存在哪里？安全吗？**
存在本地数据目录的配置文件里，明文保存、不上传。请像保管密码一样保管你的数据目录与 `.dsbak` 备份；如怀疑泄露，去提供商后台重置 Key。

**Q2：导入 Live2D 角色后是一张占位脸？**
缺少 Cubism Core 运行库。到 Live2D 官网下载 `live2dcubismcore.min.js`，放入数据目录的 `cubism` 文件夹（见 §4「角色包」）后重启即可。

**Q3：鼠标穿透开了以后点不到角色了，怎么恢复？**
这是穿透的正常效果。用托盘图标中键、托盘右键菜单或全局热键（默认见 热键 页）再切一次即可恢复互动。

**Q4：怎么把数据搬到新电脑？**
旧电脑：Hub → 系统 → 数据 → 导出 `.dsbak`。新电脑：安装后在同一页面导入该文件并重启。注意 API Key 不在备份里，需要重新填写。

**Q5：杀毒软件报毒 / 拦截怎么办？**
未签名的 Electron 应用可能被误报。请从官方发布页下载安装包，校验无误后在杀软中添加信任；正式版会逐步加入代码签名以减少误报。

**Q6：回复报错「钥匙好像不对 / 额度用完」是什么意思？**
分别对应 API Key 无效（去 模型供应商 页重填并保存）和提供商限流/欠费（换个模型或稍后再试）。详细错误可在开启开发者模式后于 诊断 页查看。
